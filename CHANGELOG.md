# Changelog

All notable changes to NotBitLee are listed here. The project follows [semantic versioning](https://semver.org).

## 1.0.0 (2026-11-17)

First public release.

- One-click **Deploy to Cloudflare**: the database is created and migrated for you, and the app works straight away on `workers.dev`
- Short links with custom back-halves, served from your own domain
- Dashboard at `/admin` with Home, Links, Analytics and Settings
- Click analytics: clicks per day, countries and referrers, per link and account-wide
- QR code for every link, downloadable as PNG or SVG
- UTM builder on the create form
- Email and password sign-in, optional Google sign-in, owners and members, lockout after repeated failed attempts
- White-label branding: name, colour, logo, home page and an optional “Powered by” line
- Branded 404 page for unknown links
- Bitly CSV import from the dashboard or the command line
- Archive and delete links
